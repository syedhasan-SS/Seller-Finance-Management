## Session Type

**Hi-Tea / casual discussion** — small-group format with light structure.

- **Zone (8 May):** in-person, 90 min, single table (5 sellers + Fleek hosts).
- **Non-Zone (22 May):** virtual, 60 min, breakout rooms by theme (Refunds/QC, Payouts, Listings, Support).
- **Group size per table/room:** 5–7 sellers max — preserves candor.
- **No formal presentation deck.** One context slide only (≤2 min): NPS journey + why we invited you.
- **Bilingual** (Urdu primary, English allowed).
- **Listening-led, ~80/20:** Fleek facilitates; sellers hold the floor.
- **No live commitments** outside a pre-approved 3–5 quick-win list.

### Flow (90-min Zone session; 60-min Non-Zone is condensed)

| Time | Block |
|---|---|
| 0:00–0:10 | Tea + welcome + one-slide context |
| 0:10–0:30 | Round-robin: each seller's biggest frustration (90 sec each) |
| 0:30–1:10 | Themed deep-dive (single table for Zone; breakouts for Non-Zone) |
| 1:10–1:25 | "What single change moves you 6→9?" |
| 1:25–1:30 | Close + 7-day "You Said / We Did" promise |

## How this improves NPS

1. **Cohort uplift:** Re-survey Hi-Tea attendees in the post-Eid wave — target ≥30% move up at least one bucket.
2. **Insight → product:** Verbatims feed the Q2 PRD backlog; commitments shipped in 30/60/90 days lift broader NPS.
3. **Anti-Detractor narrative:** "You Said / We Did" memo within 7 days breaks the *"they don't listen"* trope — the single biggest Detractor theme historically.
